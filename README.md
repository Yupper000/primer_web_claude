# G · Reel Trace

Archivo personal de reels de Instagram analizados (audio + texto + traducción).

## Sitio

Abre en el navegador:

```bash
# desde la raíz del repo
python3 -m http.server 8080 --directory reel-archive
```

Luego visita `http://localhost:8080`.
