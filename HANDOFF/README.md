# HANDOFF → Mac

Paquete listo para ver en tu laptop (sin links externos).

## Motor PAZ · Quick-Look

1. En la Mac, abre Cursor / terminal en este repo.
2. Trae la rama:
   ```bash
   git fetch origin cursor/taller-motores-emocionales-paz-2654
   git checkout cursor/taller-motores-emocionales-paz-2654
   ```
3. Abre el HTML en el navegador:
   ```bash
   open HANDOFF/Motor-PAZ/ABRIR-EN-MAC.html
   ```
   (o doble clic en ese archivo en Finder)

Verás la web renderizada con las 9 imágenes (conjuntos A / B / C).
