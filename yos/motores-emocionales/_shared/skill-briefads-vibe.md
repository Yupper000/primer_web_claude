# Skill · BriefAds VIBE (Motores Emocionales)

## Cuándo usar
Cuando Mauricio pida opciones para representar una **emoción/sentimiento** (o eje país/comunidad) antes de fijar estilo de campaña.

## Inputs mínimos (99%)
1. `emocion` (o eje: país/comunidad)
2. `avatar` (quién)
3. `contexto_entorno` (dónde / atmósfera)
4. `contraste` (contra qué se lee la emoción)
5. `plataforma`

## Proceso
1. Abrir / crear carpeta `yos/motores-emocionales/<emocion>/`
2. Escribir `motor.json` (hipótesis + métrica + sets)
3. Generar **3 conjuntos × 3 tomas** (igualdad de condiciones)
4. Prompts EN + copy ES
5. Publicar `quick-look.html` (capas + porqué + elección)
6. Esperar pick humano → tunear motor → (luego) subir a Prefijo/Cockpit

## No confundir
- Este taller **fabrica** primeros estilos.
- Prefijo **presenta/elige**.
- Un mix de emociones = motor nuevo, no fusionar IDs.
